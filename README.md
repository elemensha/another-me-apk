# 또 하나의 나 — Android MVP

현실에서 완료한 작은 목표가 판타지 3D 캐릭터의 경험치와 꾸미기 보상으로 이어지는 Android 앱입니다.

## APK 설치

오른쪽 **Releases**에서 최신 `another-me.apk`를 내려받아 설치하세요.

- 최소 Android 버전: Android 8.0 (API 26)
- 패키지 ID: `com.anotherme.app`
- 버전: 0.1.0
- APK 서명: v2, v3 검증 완료

처음 설치할 때 Android가 요청하면 파일을 내려받은 브라우저에 대해 **출처를 알 수 없는 앱 설치**를 허용해야 합니다.

## 포함된 기능

- 회전과 확대가 가능한 실시간 3D 캐릭터
- 의상 3종과 신발 3종
- 머물기, 인사, 기뻐하기 동작
- 오늘의 목표 완료, 경험치와 수정 획득
- 첫 목표 보상 `별빛 걸음` 해금과 착용
- 사용자 목표 추가와 능력치 기록
- 기기 내부 상태 저장과 전체 초기화

사진 기반 AI 캐릭터 생성과 건강 데이터 연동은 아직 포함되지 않은 MVP입니다. 선택한 사진은 서버로 전송하지 않습니다.
